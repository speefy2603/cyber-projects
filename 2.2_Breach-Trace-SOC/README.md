# Breach Trace: SOC Detection

## Overview

Simulated SOC monitoring and detection of threat actor activity using SMB and Pass-the-Hash techniques.

## What I Did

Built a Bash-based workflow to generate security activity, configure detection rules and monitor Elastic Stack alerts for SMB, Pass-the-Hash, SSH brute-force and hping3 activity.

## Tools

- Bash
- Elastic Stack
- Kibana
- Impacket
- SMB
- hping3

## Project Files

- `breach_trace.sh`

## Environment

Designed for a controlled SOC lab to simulate attacks and validate security monitoring and detection.

## Results

Generated attack activity and monitored the Elastic Stack to identify related security events and alerts, validating the effectiveness of the detection setup.
