# Breach Trail — Windows Forensics

## Overview

Automated forensic investigation of a compromised Windows system
using Bash and forensic analysis tools.

## What I Did

Built Bash scripts to automate memory analysis and forensic
file carving, extracting processes, network connections,
commands, DLLs, hashes and Registry information.

## Tools

- Bash
- Volatility 2
- Volatility 3
- Foremost
- Binwalk
- Bulk Extractor

## Project Files

- `memory-analysis.sh`
- `file-carving.sh`

## Environment

Designed for a controlled Kali Linux forensic lab.

## Results

The scripts automate repetitive forensic tasks and produce
artefacts that can be used to reconstruct attacker activity.

Screenshots of the analysis and extracted results are included
