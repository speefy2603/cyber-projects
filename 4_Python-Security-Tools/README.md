# Python Port Scanner

## Overview

A Python-based port scanning tool for identifying open TCP and UDP ports on a target system.

## What I Did

Built a Python script that accepts a target IP or hostname, scans a user-defined port range, identifies open ports and retrieves available service banners.

## Tools

- Python
- Socket
- TCP/IP
- UDP

## Project Files

- `port_scanner.py`

## Environment

Designed for a controlled cybersecurity lab environment.

## Results

The scanner identifies open or filtered TCP/UDP ports, displays available service banners and saves the scan results for later analysis.
